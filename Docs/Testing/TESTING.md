# Результати тестування

Дата: 2026-10-14. API перевірено через Swagger UI та PowerShell (`Invoke-WebRequest`).

## Адмін-панель (MVC)
- [x] Вхід адміністратора (`admin` / `admin123`), без входу сторінки перенаправляють на `/auth/login`
- [x] CRUD для Users: створення, редагування, видалення, перевірка унікальності email
- [x] CRUD для Items: категорія зі списку, пошук, заборона видалення предмета з рецептами чи запитами
- [x] Actions: створення, редагування, розгляд (Approve / Reject), коментар обов'язковий при відхиленні

## REST API
- [x] `POST /api/auth/login`: правильні дані дають 200 і токен, хибний пароль дає 401
- [x] `GET /api/items` без токена дає 401
- [x] `GET /api/items` з токеном користувача дає 200 (пошук `?search=` працює)
- [x] `POST /api/actions` з токеном дає 202, id користувача береться з токена
- [x] `POST /api/actions` з неіснуючим предметом дає 400
- [x] Токен адміністратора до API не допускається (403)

## База даних
- [x] `PRAGMA foreign_key_check;` повернув 0 рядків: усі зовнішні ключі коректні
